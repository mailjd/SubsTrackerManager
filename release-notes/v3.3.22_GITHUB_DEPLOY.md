# v3.3.22 發布入口

## 已使用 Cloudflare Git 直連

本版不要求斷開。原 Worker → Settings → Build／Builds：Build command 留空，**Deploy command 設 `npm run deploy:cloudflare`**；依 `CLOUDFLARE_SPLIT_DEPLOY_3.3.22.md` 設置 Builds 變數與機密。第一次WAIT，到指定時間後Retry同一提交；驗收後COMPLETE。更新ZIP本身不能改控制台命令。

## 選用 GitHub Actions 長流程

原 repo 配置 Secrets：`CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`、`SUBSTRACKER_BACKUP_PASSWORD`；Variables：原 `SUBSTRACKER_WORKER_NAME`／需要時 `SUBSTRACKER_WORKER_URL`／`SUBSTRACKER_ENVIRONMENT`。

工作流現在**僅手動 workflow_dispatch**，不再Push自動發布。選用這條路線時先停止Cloudflare直連及其他發布器同時執行，然後原repo Actions → Safe upgrade → Run workflow。依 `SAFE_UPGRADE_3.3.22.md` 操作，維持所有必要測試、兩次備份Artifact與16分鐘維護等待。

一個原Worker一次只選一條發布路線；已有維護批次不可換另一版本新建runId覆蓋。Worker／KV／D1及加密密鑰不得重建。Test工作流成功不是部署完成。
