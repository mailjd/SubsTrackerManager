推荐流程
1. 下载默认 Excel 模板 → 2. 填写数据 → 3. 复制“订阅导入”工作表的数据区域 → 4. 粘贴到下方 → 5. 预览并导入。
订阅导入不包含密码；账号密码请在 Database 账号库中单独维护或批量导入。

支持 .xlsx / .xls / .csv / .tsv；导入模式固定为“只新增、不覆盖原有订阅”。

导入保护：Excel 导入只会创建新记录；检测到与现有订阅重复时自动跳过，绝不会覆盖原记录。
