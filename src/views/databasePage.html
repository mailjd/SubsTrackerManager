账号数据库批量导入

支持直接选择 Excel 文件导入，也支持从 Excel 复制并粘贴。默认列顺序：账号序号、账号、实名人、账号类型、Tapnow密码、即梦密码、微信密码、QQ密码。

导入规则：账号默认必须唯一；账号序号默认也必须唯一，仅“配音供应商”允许多个不同账号共用该序号。相同账号视为同一记录。实名人/账号类型填写非空值时可更新；四组工具密码分别更新，某个密码留空则保留该工具原密码。
Excel 中的密码是明文，导入 D1 后才会使用 AES-GCM 加密保存。
兼容旧版 3 列“账号序号 / 账号 / 密码”模板；旧单一密码会进入 legacy 兼容槽，不会自动归类到四个工具。
支持 .xlsx / .xls / .csv / .tsv；默认读取第一个工作表。
系统会在覆盖前自动保存当前 Database，并只保留最近 2 个完整备份版本。全覆盖需要 SuperAdmin mode。
支持带表头；也支持按 8 列默认顺序直接粘贴

新增账号

账号资料与四组工具密码独立维护；密码写入 D1 前使用 AES-GCM 加密。

按文本保存，001 不会变成 1；账号序号为“配音供应商”时允许多个不同账号重复使用。

工具密码

编辑时留空默认保留原密码；需要清除时勾选对应“清除”。

检测到旧版单一密码
旧密码无法自动判断属于哪个工具，因此继续保留但不再作为新字段使用。SuperAdmin 编辑时会显示旧密码，建议手工复制到正确工具后再保留或清理旧数据。

SuperAdmin mode

输入二级密码后，30 分钟内允许查看 Database 中已保存的账号密码。
